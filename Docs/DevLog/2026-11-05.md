# 2026-11-05 星期三

## 工作

### 1. 饰品系统设计定案

```
6 个槽位，同种饰品可占多槽，不设叠加上限
获取方式：掉在地上走过去捡（放弃三选一）
效果：一条饰品 = 一个 Infinite GE
```

### 2. 数据结构 + 组件

```
UTrinketDataAsset        DisplayName / Description / Icon / Rarity / Weight / Category / EffectToApply
UTrinketPoolDataAsset    TArray<TObjectPtr<UTrinketDataAsset>> TrinketPool
UTrinketComponent        EquipTrinket / ReplaceTrinket / RemoveTrinket / ClearAllTrinkets
                         GetSlotsCount / HasEmptySlot
                         事件 OnTrinketEquipped / OnTrinketRemoved
```

`EquipTrinket` 上限只有 `HasEmptySlot`；效果走 `ApplyGameplayEffectSpecToSelf`，handle 存在 `FEquippedTrinket::EffectHandle`。

### 3. 跑通

装 6 个 → 属性正确叠加；清空 → 回落到基础值。`showdebug abilitysystem` 里 GE 数量能对上。

## 踩的坑

| 坑 | 症状 | 根因 |
|---|---|---|
| `Instant` GE | `handle valid=NO`，清空后属性不回滚 | Instant 不产生 `ActiveGameplayEffect`，返回无效 handle |
| `if` 缺花括号 | 报"未声明的标识符"，行号在后面几行 | 下一行成了 `if` 的 body，作用域被限制 |
| `UE_LOG` 里写中文 | `C2001: 常量中有换行符` | 文件 UTF-8 无 BOM，MSVC 按 GBK 解析，中文字节里的 `0x5C` 被当转义符 |
| `TArray<TSubclassOf<UTrinketDataAsset>>` | 数据资产里选不了饰品 | 要实例却写了"类"的类型，选择器只列类 |
| 用「蓝图类」当数据资产 | 同上，选择器"无结果" | 建的是蓝图类（UClass），字段要的是实例（UObject） |
| 改名 `ClearAllTrinkets` 顺序 | 广播时数组还在，和事件语义矛盾 | 应先把数组 `MoveTemp` 出来再广播 |

## 结论

`Instant` / `Has Duration` / `Infinite` 三种 Duration Policy 决定有没有 handle、能不能撤、能不能叠。**选错不报错，只表现为"行为不对"。**

需要"装备上去、一直在、能卸下"的，一律 `Infinite`。
