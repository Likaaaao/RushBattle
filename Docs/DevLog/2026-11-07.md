## 工作

### 1. 掉落系统分层定案

```
第 1 层 数据    UTrinketDataAsset / UTrinketPoolDataAsset / ULootTableDataAsset
第 2 层 状态    UTrinketComponent（只管槽位，不知道掉落物存在）
第 3 层 流动    ULootSubSystem（只管生成，不管拾取）
第 4 层 表现    ATrinketPickup（只管自述 + 被碰到）
```

依赖单向向下，`ATrinketPickup` 不调 `ULootSubSystem`（否则成环）。

### 2. 实现

```
UTrinketPoolDataAsset::RollTrinketOne() / RollTrinketCount(Count)
    等概率、不重复（抽一个移一个），不做加权

ULootTableDataAsset
    TrinketPool / MinCount / MaxCount / Radius / PickupClass

ULootSubSystem : UWorldSubsystem
    SpawnFromTable(Table, Origin)      圆环散布 + 地面吸附
    SpawnFromTrinket(Trinket, Origin, PickupClass)
    FindGroundLocation()               从 +200 往下打射线，只查 ECC_WorldStatic

ATrinketPickup : AActor
    只有 TrinketData / Initialize / OnInitialized
    碰撞、拾取、外观全部在 BP_TrinketPickup 里
```

### 3. BP_TrinketPickup

```
Box Collision（Root）  OverlapAllDynamic + 生成重叠事件
Static Mesh（子）      无碰撞
bPicked                防同帧重复触发

On Component Begin Overlap
    → Branch(bPicked)
    → Get Component By Class(OtherActor, TrinketComponent)
    → Equip Trinket(TrinketData)
        true  → bPicked = true, Destroy Actor
        false → 什么都不做（槽满，掉落物留着）
```

### 4. 验证

生成、散布、地面吸附、拾取装槽全部通过。拾取暂用重叠触发，以后改交互式。

## 踩的坑

| 坑 | 症状 | 根因 |
|---|---|---|
| `.cpp` 第一个 include 不是自己的头文件 | `Expected XXX.h to be first header included.` + 22 个级联错误 | UBT 强制 IWYU 顺序；后面的错误全是 `generated.h` 没生成导致的模板推导失败 |
| `SpawnActor` 传空 `PickupClass` | 一按键就崩 | `UWorld::SpawnActor` 内部 `check(Class)` |
| `RollTrinketCount` 候选池为空 | 越界崩溃 | 没写 `i < count && candidates.Num() > 0`；`TrinketPool` 全 null 时前面的 `Num()==0` 检查不触发 |
| `MinCount` / `MaxCount` 无默认值 | 静默不掉落 | 默认 0 → `RandRange(0,0)=0` → 直接返回空，无日志 |
| `Radius = 5.f` | 掉落物全部重叠 | 5 UE 单位 = 5 厘米 |

## 结论

**"静默失败"比"崩溃"更难查。** 掉落系统里每个可能返回空的路径都该打日志（`PickupClass` 没配、池子为空、`SpawnActor` 失败），否则表现和"逻辑没跑"完全一样。
