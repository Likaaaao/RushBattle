## 卡住的 / 搞不懂的

今天踩了六个坑，**前三个都花了一小时以上**。

### ① 最难的：**敌人被自己的碰撞挖掉了脚下的导航网格**

**症状**：关卡里手动摆的敌人不动；定时器动态生成的同类敌人能动。**同一个高度、同一个类。**

**被误导的方向**：编辑器和 PIE 里都看不到绿色 → 一直以为「导航没生成」，反复折腾 `NavMeshBoundsVolume`、`Build Paths`、`Runtime Generation`、地板的碰撞和「可影响导航」。

**真相**：

```
敌人站在地面上
   → 它的碰撞体被当成"障碍物"
   → 生成导航网格时，在它脚下挖了一个洞（那个六边形）
   → 敌人正好站在这个洞里
   → 【它不在导航网格上】→ Move To 找不到路径 → 不动
```

**修法**：

```
BP_EnemyBase → CapsuleComponent → 【取消勾选】Can Ever Affect Navigation
BP_EnemyBase → Class Defaults   → 【取消勾选】Can Affect Navigation Generation
然后：构建 (Build) → 构建路径 (Build Paths)   ← 必须重建，把之前的洞去掉
```



### ③ `Get Player Character` 在 `On Possess` 时刻返回空

在 `AIC_Enemy` 的 `On Possess` 里写黑板：

```
获取玩家角色 (Get Player Character) → Set Value as Object (TargetActor)
```

**打印显示是空的**——`On Possess` 只触发一次，那一刻**玩家角色还没生成**，于是往黑板里写了个 `null`，永远写不进去。

**修法**：**把「写 TargetActor」从 `On Possess` 挪进 Service。**

```
BTS_UpdateCombatRange（每 0.3 秒跑一次）
   ① Get Player Character → Set Value as Object (TargetActor)   ← 顺便刷新目标
   ② 读 TargetActor → 算距离 → 写 bInAttackRange
```

**好处**：玩家一存在就会写进去；顺带支持玩家重生；「目标信息」集中在一个地方管。

### ④ `BlackboardKeySelector` 变量设不了

`将值作为对象获取 (Get Value as Object)` 的 `Key Name` 引脚「提升为变量」后，**下拉框是空的，只能选 `None`**。

**原因**：`BlackboardKeySelector`（黑板键选择器）**需要一个「黑板上下文」才能列出键名**。在任务/服务蓝图里没有这个上下文，所以设不了。**设不了 → 写入静默失败。**

**修法**：**改用 `Get Blackboard` + `Set Value as X`，它的 `Key Name` 是普通的 `Name`（名字）类型，默认值可以直接打字。**

```
变量：TargetActorKeyName     类型 Name   默认值 TargetActor
      bInAttackRangeKeyName  类型 Name   默认值 bInAttackRange
```

> ⚠️ **变量的名字**（带空格）和**变量默认值里的字符串**是两回事。
> 默认值必须是黑板键的**真名**，比如 `TargetActor`——不是面板上显示成 `Target Actor` 的那个。

**以后一律用这个写法，不用选择器。**


### ⑥ `Get Value as Object` 返回 `Object`，不能直接连 `Actor` 引脚

`Get Value as Object` 返回的是最宽的类型 `Object`，而 `Get Distance To` 的 `Other Actor` 要的是 `Actor`。

**`Object` → `Actor` 是向下转，蓝图不自动转。**

**修法**：中间插一个 **`类型转换为 Actor (Cast To Actor)`**。
（`Cast Failed` 不用接——`Is Valid` 已经挡掉了空引用。）

**原理**：

| 方向 | 例子 | 允许吗 |
|---|---|---|
| 向上转（父类） | `Actor` → `Object` | ✅ 自动 |
| **向下转（子类）** | **`Object` → `Actor`** | ❌ **必须显式 `Cast`** |

## 关键决定

| 决定 | 原因 | 放弃了什么 |
|---|---|---|
| **BT 相关的键名一律用 `Name` 变量 + 字符串** | `BlackboardKeySelector` 在任务/服务蓝图里设不了，静默失败 | 失去"下拉选键"的便利 |
| **写黑板（TargetActor）的职责放进 Service** | `On Possess` 时机太早，拿不到玩家；Service 每 0.3 秒刷新 | Service 稍微多做一件事 |
| **`Attack` 序列放 Selector 最左边** | Selector 从左到右试，重要的在前 | 装饰器必须配好 `aborts Both`，否则永远抢占 |
| **用 `Wait` 节点做前摇和冷却，不在任务里用 `Delay`** | `Wait` 被装饰器中止是安全的；`Delay` 的回调在中止后仍会执行 | 无 |
| **敌人关掉「可影响导航」** | 否则它会把自己脚下的路挖没 | 无（角色本来就不该参与导航烘焙） |
